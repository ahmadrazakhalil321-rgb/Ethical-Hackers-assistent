# SpectreOps AI — Red Team Assessment Framework

SpectreOps AI is an interactive offensive security suite powered by **Streamlit** and **Google Gemini 2.5 Flash**. Designed for security researchers, penetration testers, and Red Teams to orchestrate engagement strategies, map MITRE ATT&CK kill chains, audit test scripts, and generate professional engagement reports.

## Features
- **Target Surface Profiler**: Interactive recon strategy generator tailored by target OS, open ports, and scope depth.
- **Adversary Kill Chain Planner**: Maps threat vectors directly to MITRE ATT&CK techniques with EDR detection insights.
- **Payload & Evasion Auditor**: Analyzes test code against AMSI/AV signature triggers and refactors for research.
- **PenTest Report Generator**: Converts raw shell logs and notes into executive-ready security reports.
